# ⏳ PHANTOM WARP — 論文タイムマシン

[ResearchPhantom](https://github.com/howly23v/ResearchPhantom) のアレンジ版です。毎日の最新研究論文を、**時間旅行しながら1枚ずつ発見していく**体験にしました。

- 🌌 **背景がずっと動く**: 論文の分野ごとに景色が変わります（AIの惑星・ことばの海・まなざしの塔・粒子の宇宙・生命の森・量子の深淵・結晶の洞窟・雷の高原）。触った位置・マウス・スマホの傾きにも反応します。
- ⏳ **タイムトラベル**: 日付を選ぶと星が光の線になり、日付が回転し、いろんな世界を通り抜けて到着します。🎲 でランダムな日のランダムな論文へワープします。
- ✨ **レア度ガチャ**: 論文には N / R / SR / UR のレア度があります。解説が充実していて数値の成果がある論文ほど当たりやすく、SR・UR はカプセル演出つきで登場します。
- 🔥 **コンボ・経験値・レベル・実績・連続来訪**: テンポよくめくるとコンボで経験値が最大3倍になります。レベルアップすると紙吹雪が舞います。
- 💖 **図鑑**: 気になった論文はダブルタップで保存できます。
- 👆 **触るたびに光る**: どこを触っても波紋・火花・効果音・振動が返ってきます。

## データ

本家 ResearchPhantom が GitHub Pages で毎日公開している保存データ（`data/manifest.json`、各日の `data/snapshots/*.json` と `data/briefings/*.json`）を**読み取るだけ**です。本家側は一切変更しません。接続できないときは、同梱の `sample.json`（2026-11-03 の一部）を表示します。

ローカルでは `?data=` でデータ元を差し替えられます（例: 本家リポジトリを `rp/` にリンクして `?data=./rp/`）。

## 構成

| ファイル | 役割 |
| --- | --- |
| `index.html` / `style.css` | 画面と見た目 |
| `js/app.js` | カードをめくる流れ・レア度演出・タイムトラベル・図鑑 |
| `js/scenes.js` | 背景キャンバス（ワールドごとの景色とワープ） |
| `js/fx.js` | 効果音（WebAudio で合成）・粒子・紙吹雪・振動 |
| `js/data.js` | データの読み込み・カード化・レア度（DOM非依存） |
| `js/progress.js` | 経験値・レベル・実績・連続来訪（DOM非依存、localStorage に保存） |

ビルドは不要です。`python3 -m http.server` などで配信するだけで動きます。

## テスト

```bash
node tests/test_data.mjs
node tests/test_progress.mjs
```

`prefers-reduced-motion` を設定している環境では、動きと振動を控えめにします。効果音は画面右上の 🔊 でいつでも消せます。
